# Aryan Hussain — Portfolio 2.0

A desktop-first software-engineering portfolio built around an explorable,
procedural 3D Toronto at night. Mobile visitors receive a fast conventional
portfolio, and every essential detail is also available through Quick View.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Useful commands

```bash
npm run build
npm test
```

The opportunity banner is controlled from the single `siteConfig` object in
`app/portfolio-data.ts`.
